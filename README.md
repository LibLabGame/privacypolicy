# LibLab Game privacy pages

Public static policy/support documents only. No game source, private assets,
credentials, or backend configuration belongs in this repository.

GitHub Pages publishes `main` from `/`:
https://liblabgame.github.io/privacypolicy/farmstead-forever/

The Farmstead Forever policy describes the current **offline** client. Update it
before releasing accounts, cloud sync, leaderboards, ads, purchases, telemetry,
or other new data processing. Provisioning a Supabase project alone does not mean
the game sends it player data.

Edit the HTML directly; no build tools, JavaScript, trackers, external fonts, or
cookies are included. Preview with any static HTTP server before pushing.
